# 🌐 Spider-Man Multiverso

Este projeto apresenta uma experiência visual interativa baseada no multiverso do Homem-Aranha, destacando os filmes estrelados por Tobey Maguire, Andrew Garfield e Tom Holland.

## 🎯 Objetivo

O objetivo é criar uma interface visual envolvente onde o usuário pode explorar diferentes versões do Homem-Aranha e acessar detalhes sobre os filmes de cada ator.

## 🕸️ Funcionalidades

- Página inicial com carrossel 3D dos três atores.
- Navegação para páginas individuais com informações dos filmes.
- Reprodução automática de trailers em background.
- Galeria de imagens com suporte a Fancybox.
- Links diretos para trailers no YouTube.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- [Fancybox](https://fancyapps.com/fancybox/) para galeria de imagens
- Design responsivo
